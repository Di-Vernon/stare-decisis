# ADR-0006 — intent 오독은 audit 대상에서 제외한다

- 날짜: 2026-10-06
- 상태: 확정 (Jeffrey 비준)
- 관련: audit 설계 D2

## 맥락

원래 목표는 "작업 결과가 원래 프롬프트 의도대로 갔는지" audit이 스스로 점검하는 것이었다. 실사용 오정렬 중 의도 오독은 26.95%로 큰 비중을 차지한다(Tang et al., arXiv 2605.29442, 다중 라벨).

## 선택지

- (A) LLM이 intent를 추론해 의도 오독까지 판정한다.
- (B) 의도 오독은 audit에서 제외한다. 대신 completion report(ADR-0009)로 Claude가 결과와 자신이 선택한 해석을 드러내고, 사용자가 이를 보고 판단한다.

## 선택

**(B)**. 판단 부담이 사용자에게 남는다는 한계를 인정한다.

## 근거

- 의도 오독은 실행 결과가 "정상 동작"이어서 결정적 신호가 없다. 의도 오독의 44.10%가 프롬프트 명세 부족에서 비롯됐다(Tang et al.). [B, 실사용]
- LLM judge는 확신에 찬 마무리 문장 같은 표면 단서에 끌려간다. 거짓 완료 판정조차 AUROC가 0.54–0.65에 그쳤다(arXiv 2606.09863, 초록 기준). [B, 벤치마크]
- 모델은 명세가 잘 된 지시와 부족한 지시를 잘 구분하지 못한다(Ambig-SWE, arXiv 2502.13069). [B, 벤치마크]
- audit이 의도를 추측하게 하면 오탐 주입이 늘어난다. 오탐 주입은 누락보다 해롭다(arXiv 2604.27283).

## 영향 범위

- audit의 판정 대상은 claim과 증거의 대조, 변조, (A2 이후) 명시된 scope 위반으로 한정한다.
- 실행 전 확인 질문은 A2에서 별도로 다룬다.
