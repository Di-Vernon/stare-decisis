# ADR-0012 — A1 라벨 수집과 차단 권한 해제 기준

- 날짜: 2026-10-06
- 상태: 확정 (Jeffrey 비준)
- 관련: audit 설계 D8

## 맥락

audit 검사 항목에 개입 권한을 주려면 실사용 정밀도를 알아야 한다. 정답지는 사용자 교정뿐인데, 이것은 희소하다. 실사용 오정렬 중 해결이 가시적으로 드러난 사례는 9.33%뿐이었다(Tang et al., arXiv 2605.29442).

## 선택

### 라벨 수집

- **수동 라벨**: audit flag 이후 같은 세션 안에서 나온 사용자 교정, 되돌림, 반대 발언을 자동으로 연결한다.
  - 연결 창은 flag 뒤 N턴이다. N은 설정 가능하며 초기값은 5다(근거 없음 → E-A5).
- **능동 라벨**: 세션 종료 시 "이 audit이 맞았나?"를 묻는다. 사용자 부담을 줄이기 위해 M0에서는 기본으로 꺼 둔다(설정 가능).

### 라벨 해석

- "flag 이후 사용자가 교정" → 진양성
- "flag 이후 사용자가 반대하거나 되돌림" → 위양성
- "flag 없음 ∧ 교정 없음"은 진음성으로 보지 않는다. 따라서 재현율은 권한 해제 기준에 쓰지 않는다.

### 차단 권한 해제 (A2 이후 적용)

- 검사 항목별로 따로 판단한다.
- 라벨 n≥25이고 오탐 ≤1이면 1회 차단 후보다(Wilson 95% 하한 ≥0.80).
- 라벨 n≥55이고 오탐 ≤1이면 반복 차단 후보다(하한 ≥0.90).
- 실제 해제는 ratification을 거쳐야 한다.
- 강등은 자동이다. 최근 20건 이동 창에서 하한이 기준 아래로 떨어지면 shadow mode로 돌린다.
- 목표 정밀도 0.80과 0.90은 근거가 없는 설정값이다.

### 측정 교란 방지

- 재발 카운터를 `recurrence_user`와 `recurrence_intercepted`로 나눈다.
- intervention budget을 초과해 억제된 개입은 exposure와 별도로 기록한다.

## 근거

- Wilson 하한 표본 수는 표준 공식으로 계산했다. 오탐 1건 기준 n=25에서 0.805, n=55에서 0.904다. [D, 계산]
- 감지 결과만으로 바로 승격하지 않고 사용자 확인을 거치는 것은 R1 결론과 같은 방향이다. 단일 LLM 판정만으로는 최고 수준에서도 4분류 오류율이 26%였다(SWE-chat, arXiv 2604.20779). [B]

## 영향 범위

- 초기 intervention budget은 세션당 6이다. audit 피드백, L2 경고, L3 확인을 합산한다. 근거가 없으므로 E-A4에서 보정한다.
- 라벨 수집량은 E-A5로 확인한다.
